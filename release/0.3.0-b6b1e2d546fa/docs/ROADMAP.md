# MCS Obsidian 开发基线

日期：2026-10-15。0.2.0 在已有桌面独立视图上完成动态体验迭代：独立运动层 → 圆点／卡片与交互 → 保存／回放 → 协议迁移与笔记展开 → 实机验收。0.2.1 补上紫主题与品牌署名：站点令牌进插件、明暗跟随 Obsidian、画布配色整份刷新、本地字标与徽记，并单独加一支主题与无障碍验收。0.3.0 接入定义来源与无环检查、精确全称代入及独立有限实例／反模型重放。任意 Lean 目标适配与教材逐条审阅仍按 P3、P5 后续门槛推进。

## 为什么做

从学习者看：为了研究“为什么消元保持答案”，需要挑出适量对象、看清条件、反例和下一步；全库内部链接图没有表达联合条件与证明依据。

从研究工程看：关系需要身份、版本、背景理论和可重放证据，才能在修改条件后知道哪些结论失效。生长链是笔记引用 → 有类型的节点与关系 → 带条件的联合行动 → 可审阅证书 → 可复用的网络与学习演绎。

## 阶段与验收门槛

| 阶段 | 交付 | 门槛 |
| --- | --- | --- |
| P0 理论与来源 | 交互清单、关系语义、全书映射、案例校勘、界面原型 | 来源与假设可追溯，不把规划说成实现 |
| P1 数据与共享内核 | 版本化协议、网站规划器适配、AND/OR 与模拟状态 | 同一输入保持语义；无第二套规划器 |
| P2 组网 | 搜索推荐、三种布局、笔记绑定、视图库、导入导出 | 重启与跨库恢复；移出视图不删除内容 |
| P3 形式关系 | 编辑、语法类型检查、ND/Lean 验证适配、失效传播 | 改条件后旧证据不继续显示有效 |
| P4 动态演绎 | 实际输入、事件回放、不同背景与备选路线 | 跳步一致；模拟不写真实掌握 |
| P5 教材案例 | 八章七程地图、方程组到解空间的完整示范链 | 正文、反例、证明、来源、回看问题齐备 |
| P6 发布验收 | 插件包、示例库、手册、验证记录 | 实际 Obsidian 安装与恢复；保留验证边界 |

阶段状态以 README 的实际交付记录为准。本表是 DEF 规格，不是完成报告。

## 产品约定

- 独立 MCS 文件视图；使用 Obsidian 公开 API，不修改核心 Graph 的内部实现。
- 默认中文，首轮 Windows 桌面。账号同步、移动端和数学对象动画另行安排。
- 加法式组网、光标缩放、增量摆位、手动位置优先、三种布局与布局参数保存。
- 推荐区分图中已有、学习者确认和模拟背景；理由必须来自具体关系或契约。
- 内容 M、学习者记录 E、派生图与路线 D 分层；本地内容修订不写回网站公共内容。
- 关系默认人工采用；检索与有界发现只产生候选；未知不解释成不成立。
- 以给定路线事件为回放单位，保留复习和不产生新节点的步骤。
- 便携包默认包含内容及视图，不包含个人学习记录。导入冲突先展示，保留双方。
- 主题令牌以站点 `mcs-web/web/src/styles.css` 的 `:root` 为唯一权威源；插件只在 `src/theme.css` 里镜像一份，作用域限工作区与设置页，明暗跟随宿主的 `theme-dark` / `theme-light`。
- 画布颜色只有一套：SVG 走 CSS 变量，二维 Canvas 回退与 WebGL 图层读同一份令牌镜像，切换主题必须整份重建，不能留半套旧色。

## 检查计划

AND/OR、隐藏前提、错误目标、错误类型、无界搜索误报、证据过期、定义循环、合法等价环；笔记改名与缺失、并发保存、损坏输入、重复导入；模拟隔离、回放跳步、布局撤销；200 节点/600 联合行动持续拖动及缩放，帧间隔第 95 百分位目标 ≤33ms，收敛后停止循环。

理论证据标签沿用 DEF / PROOF / REF / FINITE / ILLUSTRATION / NOT-CLAIMED。机器检查与原文对应审阅分别记录。试用反馈不构成一般教学收益证明。

回看：学习者能否解释“这条边凭什么成立”？能否区分“这个证明用了 A”与“所有路线都必须学 A”？

思想：让每一条可操作关系同时拥有自然解释与可核查义务。方法：先固定语义和版本，再组图、规划和回放。
