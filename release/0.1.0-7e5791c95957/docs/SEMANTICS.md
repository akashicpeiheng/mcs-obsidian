# 关系、视图与学习状态的语义

## 先看整体

DEF：内部链接用于打开材料；MCS 关系另外存储类型、条件、来源和证据。图上的连线是这些记录的展示。笔记和卡片不是天然一一对应，稳定节点 ID 才是数学对象的身份。

## 关系的检查义务

| 类型 | 自然读法 | 检查义务 | 不能推出 |
| --- | --- | --- | --- |
| definitionReference | 这个表达用到了那个定义 | 明确符号出现、版本、无定义循环 | 此概念已被学习者掌握 |
| scaling | 在这些条件下，特殊情形满足一般描述 | 固定背景、精确方向、条件输送见证 | 任意反向蕴含或可逆映射 |
| equivalentTo | 两个精确陈述在同一背景下互推 | 两个方向的目标与证据 | 两者的学习成本相同 |
| conditionalDerivation | 这些前提共同支持该结论 | 联合输入、完整条件、目标、开放假设 | 任一输入单独充分 |
| instanceOf | 指定对象满足该描述 | 类型正确的代入与满足见证 | 有限实例代表一般证明 |
| counterexampleTo | 对象满足假设但违反结论 | 假设真、结论假、解释与载体 | 搜索失败就是反例 |
| topic / analogy | 值得放在一起比较 | 明确比较面和边界，人工审阅 | 逻辑蕴含或必修先置 |
| 教学行动 | 按这一教学方案，从输入组织到输出 | 全部输入、资源类型、来源事件 | 已证明一般数学定理 |

DEF：同一行动的输入是 AND，同一目标的不同生产行动是 OR。显示时用汇合点保留 AND，不把它拆成几条分别充分的边。所选事件来源必须无环；等价关系的双向连通并不因此被拒绝。

数学判断、运行状态、人工审阅是三个字段。PROOF 可表示已有纸笔论证，不能独自点亮“本机机器验证”。检查器不支持或运行失败保持未知；仅独立核对目标、背景、开放假设和版本后才能展示有效机器证据。

## M / E / D

- M：版本化内容快照与本地作者修订。旧版本和原来源保留。
- E：确认记录、个人备注、视图选择、手动位置。浏览、加入节点、播放不自动确认掌握。
- D：根据指定 M、E 与参数生成的候选、路线和视图。模拟 E 是独立副本。

学习闭包意味着资源在指定模型下可用，不意味着真实心理状态增长。遗忘会影响学习建议，不抹掉已存在的数学证明。

## 视图与路线

视图保存内容版本、节点集合、边类型设置、坐标、锁定点、布局模式、锚点与相机。学习顺序布局用所选事件依赖的最大前置层次，不能只按距起点的最短距离排序。

路线保存独立事件 ID、行动 ID、输入来源和 OR 选择，不只保存节点串。回放按精确事件推进，已有集合不等于实际使用集合；起始背景为空时保持空帧，不把第一步结论提前当背景。
